# Day 24

A new timer mode control was added to the Focus page today. The student can now choose between Focus mode and Break mode before starting the timer.

Focus mode keeps the normal 25-minute Pomodoro session and lets the student choose a course. Break mode uses a five-minute timer and shows a simple message instead of the course selection. I used different icons and colors for the two modes, so it is easier to see which mode is active.

When the user changes the mode, the timer resets to the correct time. The mode switch is also locked while the timer is running. This prevents the timer from changing from 25 minutes to 5 minutes in the middle of a session.

I also made sure that only completed Focus sessions are added to the focus progress count. Completing a Break session does not change the academic focus statistics. Next, I will create a page section for focus session history.
