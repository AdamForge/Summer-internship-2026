# Day 21

The Pomodoro timer is easier to control now. I improved the Pause button and added Continue and Reset controls.

After pausing, I can continue the same focus session without losing the remaining time. The Reset button stops the timer and returns it to 25:00. I also added different button names and messages for each timer state, so it is easier to understand what is happening.

Today I learned that one timer can have several states and each state needs the correct button behavior. Next, I will add course selection for focus sessions.
