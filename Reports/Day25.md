# Day 25

The Focus page now has a Session History section. Before the app only showed the last completed Pomodoro session. Now every finished Focus session is added to a list.

Each item shows the course name, the session length, and the time when it was completed. New sessions appear at the top of the list, so the student can quickly see their latest study sessions.

I also added a simple message for when there are no completed sessions yet. This helped me learn how to show a list in SwiftUI and how to keep it connected to the ViewModel. Next, I will improve timer states and check some user input cases.
