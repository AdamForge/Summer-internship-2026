# Day 19

day 19 was about finishing one more important part of the Tasks section. I added a delete option for tasks. Now when I open a task detail screen, I can press Delete Task. And before deleting, the app shows a confirmation alert, so the task is not removed by mistake.

After the task is deleted, the app goes back to the main Tasks page. The task disappears from the list, and the overview numbers update too.

Now the Tasks section feels more complete because I can add, edit, mark as done/open, and delete tasks. The data is still only local mock data for now, so saving after restart will be added later.
