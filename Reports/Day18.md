# Day 18

Today I continued working on the Tasks section.

I added an Add Task button to the main Tasks page. Before this, I could edit tasks, but I could not create a new one from the list screen. Now the app opens the task form when I press the add button.

After I fill in the task information and save it, the new task is added to the top of the list. The small overview card also changes automatically, so the number of open, done, and high priority tasks stays updated.

This was a good step because the Tasks page is not only showing mock tasks anymore. It can now create new tasks during the app session. Later, I still need to add real saving, so the tasks do not disappear after restarting the app.
