# Day 15

Today I made the Tasks section interactive.
Before this, tasks were only shown on the screen. Now I can tap the task status button or the circle icon to change a task from Open to Done, or from Done back to Open.

I also updated the task logic in the model and ViewModel. When a task changes status, the task overview numbers update too, like open tasks and completed tasks.

As I mentioned in earlier days, the tasks are still mock data, so they do not stay saved after restarting the app yet. Next, I will continue improving the Tasks section.
