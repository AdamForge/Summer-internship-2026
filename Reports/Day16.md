# Day 16

For this day, I worked on the Tasks section and added a separate detail page for each task. Before this update, the Tasks page only showed a simple list. Now I can open a task and see its title, course name, due date, priority, and status on another screen. This makes the task part of the app feel more complete.

I also added a button inside the detail page to change the task status between Done and Open. When I change it, the list and the overview numbers update too.
