# Day 17

For Day 17, I worked on the task form screen.
I created a new screen where a task can be edited. The form has fields for the task title, course name, due date, priority, and status. I also added a small preview card, so I can see how the task will look while changing the form values.
I connected this form to the task detail page with an Edit button. Now, when I open a task, I can also open the edit screen and change the task information.
