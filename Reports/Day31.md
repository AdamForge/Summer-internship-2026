# Day 31

For the final day, I checked the main parts of UniLifeGlass and fixed some small problems I found.

One important problem was in the course form. The Save button closed the screen, but it did not actually add or update the course. I connected the form to the main data, so now a new course can be added and an existing course can be edited. The changes are also saved on the device.

I also changed a few old messages in the course, exam, and task forms. Before, some screens said that the data was only mock data. Now the messages explain that changes are saved on the device.

Finally, I built the project again and checked that the main screens and navigation still work together. The app now has working tabs for Home, Lessons, Exams, Focus, and Tasks, with local saving for the main student data.
